Проверялись реальные rendered страницы. Снимок `artifacts/ui-desktop.png` содержит только синтетическое обращение и не включается в npm-пакет. Временные viewport overrides сбрасывались после проверки.

Первоначальные тесты обнаружили ошибки коротких es/pt-фраз и пустого demo seed. Независимое ревью затем обнаружило, что FAQ мог скрыть содержательный инцидент, упоминание отсутствующих материалов считалось доказательством, а HTTP/core имели два разных валидатора. Эти дефекты исправлены с сохранением регрессионных проверок. Успешные проверки до исправлений не используются как доказательство финальной готовности.

Docker проверен отдельно от локального Node: Docker Desktop 28.4.0, `node:22-alpine`, фактический Node внутри контейнера v22.23.4. Код и собственные инструкции входят в образ, приватные правила подключаются через read-only mount. Контейнер не запускается от root. Публикация порта ограничена 127.0.0.1.

Оценка классификации и задержки описывается отдельно в `evaluation.md`. Подтверждение носителями kk/uz, слепая оценка администраторов, интеграция с игрой и промышленная авторизация в эту локальную проверку не входят.

# Support Copilot — отчёт для жюри

Support Copilot — локальное рабочее место поддержки с веб-интерфейсом, HTTP API и пакетным CLI. Оно объединяет очередь обращений, триаж, поиск по правилам, подготовку черновика, ручную правку и историю решения. Для работы не нужен внешний LLM API или API-ключ.

## Соответствие критериям

| Критерий | Что реализовано |
|---|---|
| Качество черновика — 30% | Проверяемый контекст, сообщённые игроком сведения, локализованный ответ и передача сложного обращения сотруднику. Расширенная модельная генерация проходит отдельную квалификацию и сейчас не включена; результаты приведены в техническом отчёте. |
| Классификация — 25% | Категории из таксономии кейса, приоритеты p0–p3, объяснение решения и семантический маршрутизатор, обученный на 1134 авторских примерах. |
| Grounding — 20% | Локальный E5 + BM25, проверка canonical ID и применимости правила. В текущем замере проверены 135 из 135 ссылок; это целостность источников, а не оценка relevance. |
| kk/uz — 15% | Общий путь обработки на шести языках: ru, kk, uz, en, es, pt. Авторские проверки не заменяют оценку носителями языка. |
| Стоимость — 10% | Внешние API-вызовы отсутствуют: $0. Стоимость локального CPU и электричества отдельно не оценена. |

Проценты — веса критериев кейса, а не присуждённые команде баллы. Gold accuracy, priority macro-F1, blind admin rating и экспертные языковые оценки не заявляются без соответствующей разметки.

## Проверенная работоспособность

- 598 обычных тестов прошли без ошибок; модельные пропуски указаны отдельно. В распакованном публичном архиве также прошли 598 тестов после фактического offline npm ci.
- 1217 проверок HTTP, CLI, GNU Make и локального workflow прошли на 14 авторских обращениях.
- Реальный E5 обработал 1000 обращений напрямую и 1000 через HTTP. HTTP p95 — 39,95 мс; ошибок HTTP и схемы ответа нет. В этом консервативном наборе 1000 из 1000 обращений оставлены человеку; это не доказательство точности классификации или auto-reply coverage.

По умолчанию сохраняется режим подтверждения сотрудником. Автоответ допускается только после квалифицированной генерации и всех human/safety/manual-state проверок; ручная правка защищена от устаревшего результата модели. История различает AI auto и явное подтверждение локального оператора, но отправка в игру не подключена: `external_delivery=false`.

## Комплект и воспроизведение

В [README](../README.md) приведены Node.js 22, npm ci, отдельный приватный DATA_DIR, установка E5, loopback URL, точный HTTP-вход и Make IN/OUT. Публичная поставка содержит исходники, lockfile и авторские примеры; handout, реальные JSONL, веса, индексы и рабочая очередь исключены. Восстановленная 20-step модель сохранена локально; её наличие само по себе не означает успешную квалификацию полного ответа.

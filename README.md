# Support Copilot — Grand Mobile

Локальное рабочее место поддержки: очередь обращений, триаж, поиск по правилам, черновики на шести языках и контроль ответа сотрудником. Работает через веб-интерфейс, HTTP API и пакетный CLI. Внешний LLM API и API-ключ не нужны.

## Комплект сдачи Support Copilot

| Требование | Где проверить |
|---|---|
| HTTP-сервис `POST /triage` по контракту | [Запуск и пример запроса](#http-api), реализация в `src/server.mjs` |
| `make predict IN=tickets.jsonl OUT=pred.jsonl` | [Пакетный контракт](#пакетный-контракт), общий CLI для HTTP-совместимого результата |
| Метрики и примеры черновиков | [Итоговый отчёт](docs/evaluation-v3.md), включая авторские примеры RU/KK/UZ |
| Доля `needs_human`, стоимость и время обработки | [Итоговый отчёт](docs/evaluation-v3.md): 1000/1000, внешние API $0, HTTP p95 39,95 мс в описанном локальном замере |
| Инструкции установки, настройки и запуска | Разделы ниже, `.env.example` и [руководство по хостингу](docs/hosting.md) |

Критерии жюри: качество черновиков — 30%, классификация — 25%, отсутствие выдуманных правил — 20%, казахский и узбекский — 15%, стоимость и задержка — 10%. [Соответствие реализации критериям](docs/submission-v3.md) содержит результаты и границы измерений. Презентация и видео для этого кейса не обязательны.

Данные Grand Mobile предоставляются проверяющему отдельно и не входят в публичный репозиторий. Опубликованные примеры созданы авторами проекта; реальные обращения и производные выборки не публикуются. Согласно FAQ конкурса, материалы нужно удалить в течение 14 дней после объявления победителей, если отдельное соглашение не предусматривает иное.

## Возможности

- Категория и приоритет p0–p3, извлечение сообщённых сведений, объяснение `needs_human`.
- Поиск multilingual E5 small ONNX int8 + BM25 по локальному корпусу. Только проверенные canonical IDs становятся цитатами; поисковые кандидаты сами по себе не доказывают применимость правила.
- Очередь, ручная правка, подтверждение, эскалация, feedback и история. Состояние сохраняется после перезапуска; импорт поддерживает checkpoints.
- Радар похожих проблем, инструкции оператора и сравнение версий с явным происхождением меток.
- Режимы «С подтверждением сотрудника» и «Автоответ» сохраняются. По умолчанию включён review. Автоответ требует квалифицированную локальную генерацию и все защитные проверки; платёж, риск, жалоба, ручная правка или ошибка оставляют обращение сотруднику.

Языки интерфейсных ответов: ru, kk, uz, en, es, pt. Результат — локальный outbox: `external_delivery=false`, отправка в игру не подключена. Ответы не применяют санкции и не гарантируют возврат средств или снятие блокировки.

## Запуск за несколько минут

Нужны Node.js 22+ и npm. Приватные `rules.json` и `taxonomy.json` из материалов кейса предоставляются отдельно; их нет в архиве исходников. Реальные обращения для старта не нужны: первая очередь содержит авторские демонстрационные примеры.

```powershell
npm ci
$env:DATA_DIR = 'D:\private\grand-handout'
$env:LOCAL_GENERATOR = '0'
$env:TRIAGE_DRAFT_MODE = 'fast'
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Также доступен `start-support.cmd`. `.env.example` описывает параметры, но `.env` автоматически не загружается. Путь `DATA_DIR` задаётся локально: не копируйте приватные материалы в репозиторий.

Для семантического поиска один раз выполните `npm run models:setup`, затем нажмите **Подготовить поиск**. Установка явно загружает открытые веса; дальнейшая работа использует локальные файлы. Готовность и fallback видны в интерфейсе. Без E5 включается базовый поиск; это не равнозначно семантическому режиму.

По умолчанию: `HOST=127.0.0.1`, `PORT=3000`, `RUNTIME_DIR=./runtime`, `MODEL_DIR=./runtime/models/multilingual-e5-small`, `INDEX_DIR=./runtime/indexes`. Один runtime имеет одного записывающего владельца. При обновлении сохраняйте runtime; не снимайте активный marker вручную.

## HTTP API

```powershell
$body = '{"kind":"report","lang":"en","messages":[{"role":"player","text":"Hello! I am new here and need help getting started."}]}'
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:3000/triage' -ContentType 'application/json' -Body $body
```

Пример входа авторский. Обязательные поля ответа: `lang`, `category`, `priority`, `is_spam_or_duplicate`, `extracted`, `draft_reply`, `needs_human`, `confidence`, `reasons`. `draft_reply.text` содержит текст, `citations` — применимые источники, `analysis` — режим и объяснение. Scores эвристические, а не калиброванная вероятность. `POST /triage` не отправляет ответ и не создаёт исходящее сообщение.

В inference используются сообщения игрока; ответы администратора и исторические outcomes исключаются. Сведения игрока остаются неподтверждёнными, содержимое вложений недоступно. При недостатке оснований приложение уточняет данные или передаёт обращение сотруднику.

## Пакетный контракт

```powershell
make predict IN=../handout/tickets_valid.jsonl OUT=artifacts/private/pred-v2.jsonl
make predict MODE=baseline IN=../handout/tickets_valid.jsonl OUT=artifacts/private/pred-v1.jsonl
# Если GNU Make не установлен:
node src/cli/predict.mjs --in ../handout/tickets_valid.jsonl --out artifacts/private/pred-v2.jsonl --mode v2 --initialize
```

Одна строка JSONL на каждый вход; порядок сохраняется. Каталог вывода приватный. `make predict` вызывает тот же CLI и явно подготавливает поиск; при отсутствии модели возвращается честно помеченный fallback.

## Работа сотрудника

Откройте обращение → «Помощь с ответом» → «Подготовить черновик» → проверьте предложенный текст → «Применить в редактор» → отредактируйте и подтвердите. Подготовка черновика работает без LLM, не затирает вашу правку и позволяет вернуть предыдущий текст. Отдельный запуск локальной модели доступен при её подключении и проходит серверные проверки. Сохранённая история различает AI auto и подтверждение локального оператора. Возврат в review и перезапуск не превращают старые обращения в автоматические задания.

Настройки доступны через `GET /api/settings`, `PATCH /api/settings` с `reply_mode` и `revision`; локальные ответы — `GET /api/tickets/:id/replies`. Автоматический ответ не имитирует human approval. Внешнего игрового транспорта в поставке нет.

```powershell
npm test
npm run package:check
npm run evaluate:v2
node scripts/check-recovery-v2.mjs
```

- **598 обычных тестов прошли без ошибок.** Два native-теста пропущены, два теста с реальной E5 не выбирались. В отдельно распакованном публичном архиве также прошли 598 тестов; четыре модельных теста пропущены из-за отсутствия весов.
- **1217 проверок HTTP, CLI, GNU Make и локального workflow прошли без ошибок** на 14 авторских обращениях. Проверены настройки review/auto, ручные правки, локальная история и перезапуск.
- **1000 обращений обработаны напрямую и через HTTP с реальным E5.** HTTP p50 — 17,95 мс, p95 — 39,95 мс; ошибок HTTP и схемы ответа нет. Инициализация, первый запрос и 20 прогревочных запросов учитывались отдельно.

Проверенный source: `8b3fe1b413448ab15986ed5365ecd8fa72393d424559983c447b421a01a070d6`. Методика, результаты генерации и ограничения описаны в [техническом отчёте](docs/evaluation-v3.md), краткое соответствие критериям — в [отчёте для жюри](docs/submission-v3.md).

## Локальная модель и обучение

Маршрутизатор обучен на 1134 авторских примерах; модель плана Qwen3-0.6B прошла реальное дообучение в 20 шагов на 36 TRAIN-примерах с 12 holdout-примерами, а восстановленные веса сохранены локально. Расширенная native-генерация остаётся отдельным режимом проверки и выключена по умолчанию; её текущие результаты и условия допуска приведены в [evaluation-v3](docs/evaluation-v3.md).

## Docker — опциональный запуск

```powershell
docker build -t support-copilot:0.3.0 .
docker volume create support-copilot-state
docker run --rm -p 127.0.0.1:3001:3000 --mount type=bind,source=D:\private\grand-handout,target=/data,readonly --mount type=volume,source=support-copilot-state,target=/app/runtime support-copilot:0.3.0
```

Docker использует Linux Node22/glibc, nonroot-пользователя и отдельный runtime volume. Без model mount работает fallback; подготовленную E5 можно отдельно смонтировать в `/models/e5`. Windows native runner в этот образ не включён. Команды Docker приведены; образ 0.3 в этом цикле не проверен.

## Данные и границы

Публичная поставка содержит код, lockfile, авторские fixtures и документацию. В ней нет handout, реальных обращений, весов, индексов, runtime и секретов. API-вызовы стоят $0; CPU/электричество/локальная память отдельно не оценены. Gold category/priority и экспертная оценка kk/uz: **не предоставлены**, если явно не указано обратное в итоговом отчёте. Это локальное рабочее место; промышленная авторизация и внешнее развёртывание в текущую поставку не входят.

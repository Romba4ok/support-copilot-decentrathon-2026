# Workspace v2 implementation checkpoint

Saved on 2026-10-30. Owner: backend executor. Scope: T001, no commit, push, publication, or live private runtime mutation.

`state.json` keeps the v1 queue/feedback schema. `workspace.json` independently and atomically stores jobs, annotations, comparison rows and metrics, radar, and template lifecycle history. Pending/running jobs recover as interrupted/resumable. Import queue IDs are deterministic per job and record, so a crash between the durable queue write and job cursor update does not duplicate an imported record.

`createApp()` stays synchronous and defaults to baseline when no intelligence service is passed. The production entry constructs the local intelligence service without loading/downloading models. Explicit initialization runs as a durable job. MODEL_DIR and INDEX_DIR override only application model/index locations. Existing v2 triage projections survive startup without baseline downgrade. Explicit re-analysis preserves operator draft/status; generation records a separate proposed draft and preserves `edited_reply` until an operator saves it.

HTTP v2 routes follow plan.md. Additive `GET /api/search?q=...&limit=...` returns the intelligence search contract. All route IDs use decoded paths after traversal validation, including imported IDs with encoded colons. Host/Origin/CSP controls still cover every endpoint. Imports accept JSON tickets or JSONL strings, never local paths, up to 2 MiB and 1000 records. Jobs expose progress/error/resumable fields but never their private payload. The existing queue capacity is 10000.

Only explicit annotation POSTs write human provenance; ticket creation/import/inference never does. Comparison supplies the same sanitized input to baseline and v2 and holds labels in a separate field. Every metric has a denominator; unlabelled metrics are null. kk/uz slices are explicit. Category accuracy, priority macro-F1, language accuracy, human-risk recall, auto precision/coverage, citation integrity, manually labelled source relevance and latency are available. Quality UI receives aggregate comparison summaries; complete comparison rows remain available in the explicit compare response and private workspace state.

Radar uses lexical token overlap when the model is unavailable, or source affinity derived from semantic retrieval when ready. The method and threshold are visible. Similarity never sets the core duplicate flag. Template proposals contain origin IDs and real rule source IDs; edit returns a template to proposed; approval and revoke are explicit. The production intelligence service dynamically reads approved templates, so revoked instructions disappear immediately without rebuilding the official source index.

`predict.mjs` preserves the baseline CLI default. Explicit `--mode v2 --initialize` loads installed local models only; missing models yield visible fallback. `--initialize` with baseline is harmless. `scripts/import-tickets.mjs` streams a local JSONL file in bounded batches and saves private checkpoints under runtime/imports. Repeat the same command and batch size to resume. No HTTP request can select a local path.
